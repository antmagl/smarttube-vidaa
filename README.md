# SmartTube for VIDAA — hosted build

This repository contains the built static web app from the `vidaa/` directory of
[yuliskov/SmartTube](https://github.com/yuliskov/SmartTube). It is published for
use as a Sidee launcher tile on Hisense VIDAA TVs.

- Open the app: https://antmagl.github.io/smarttube-vidaa/
- Install: add that address in Sidee's SmartTube card, or run
  `python sidee.py install smarttube`
- No server is required. It is a static site; history and settings stay in the
  TV browser.
